# CodeAlpha Internship - Task 2: Build a Calculator

This project is a fully functional basic calculator built using **HTML, CSS, and Vanilla JavaScript** as part of the CodeAlpha Web Development Internship.

## Features
*   **Basic Arithmetic Operations:** Addition (+), Subtraction (-), Multiplication (×), and Division (÷).
*   **Clean UI:** A modern, user-friendly interface with a display screen and buttons.
*   **Real-time Result:** Instantly calculates the result when the equals (=) button is pressed.
*   **Error Handling:** Displays "Error" for invalid inputs and clears automatically.
*   **Bonus Features:**
    *   **Keyboard Support:** Users can type numbers, use operators, hit `Enter` to calculate, `Backspace` to delete, and `Escape` to clear.
    *   **Styling Enhancements:** Hover effects, active button states, and a responsive design.

## Technologies Used
*   HTML5
*   CSS3
*   JavaScript (ES6)

## How to Run
1. Clone this repository or download the files.
2. Open `index.html` in any modern web browser.
3. Enjoy calculating!
